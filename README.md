# AI学生 · Windows 桌面端角色扮演 AI Agent

> 一个会自动"听课"的 AI 学生：用麦克风听老师讲课，抓取**极域电子教室**的远程演示画面，
> 全程录像留档，边听边理解，自动识别老师布置的作业并完成，最后把作业写到**你指定的文件夹**里。

软件本体是一个 Windows 桌面程序（Python + PySide6），**不是**网页、不是脚本集合。
双击 `启动AI学生.bat` 即可以图形界面运行。

---

## 一、它到底做什么

| 环节 | 说明 |
|------|------|
| ① 采集音频 | 麦克风（听教室里的老师）+ 系统回环（听电脑里播放的声音），两路可独立开关，自动混音 |
| ② 采集演示画面 | 按关键字自动定位"极域电子教室 / TopDomain / 教师演示"窗口并抓取其画面；找不到窗口时退回整屏 |
| ③ 全程录像 | 整段 `audio/audio.wav` + `screen/video.mp4`（H.264）；另按画面变化存关键帧 `kf_xxxx.jpg` |
| ④ 边听边理解 | 音频按片段送多模态模型转写成文字；画面关键帧送视觉模型读出板书/PPT/题目 |
| ⑤ 生成课堂笔记 | 把转写 + 板书滚动汇总成结构化 Markdown 课堂笔记（知识点 / 板书要点 / 布置的任务 / 存疑） |
| ⑥ 识别任务 | 从笔记与老师原话里抽出"老师布置了什么"，带置信度、要求、截止时间，自动去重 |
| ⑦ 完成任务 | 结合课堂笔记 + 相关原话 + 板书要点作答，产出解题过程并自检 |
| ⑧ 产出作业 | 写成 `md / txt / docx` 到你的输出目录，并生成 `作业汇总.md`、`课堂笔记.md`、`课堂时间轴.md` |

所有素材（音频、录像、关键帧、转写、笔记）都留在会话目录里，**随时可回查**，也方便你把
某一段喂给 AI 重新分析。

## 二、系统要求

- Windows 10 / 11（x64）
- Python 3.10+（本项目在 CPython 3.14 + PySide6 6.11 上开发验证）
- 一个多模态大模型的 API KEY（推荐阿里云百炼 / 通义千问，中文课堂效果最好，且自带语音识别）
- 可选：麦克风；没有麦克风时只录系统回环也能用

## 三、快速开始

### 1. 安装依赖

```bat
cd /d D:\Code\MixProject\AI学生
python -m venv --system-site-packages .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. 启动

双击 `启动AI学生.bat`，或在命令行：

```bat
set PYTHONPATH=%CD%\src
.venv\Scripts\python.exe -m ai_student
```

### 3. 首次配置（必须）

第一次启动会自动弹出**首次运行向导**，三步：

1. **模型 API**：选服务商预设 → 填 API KEY → 点「测试连接」确认可用。
   - 通义千问：到 https://bailian.console.aliyun.com/ 开通并创建 API KEY
   - 预设会自动填好 `base_url / 对话模型 / 视觉模型 / 语音识别模型`
   - API KEY 用 **Windows DPAPI 加密**后存在 `%APPDATA%\AIStudent\config.json`，只有当前 Windows 用户能解密
2. **个人信息**：姓名、学号、班级、学校、任课教师、科目、作答风格。作业文件会用这些信息署名。
3. **作业输出**：选一个文件夹，作业就写到那里（默认 `我的文档\AI学生作业`）。

### 4. 开始听课

在「听课」页点 **开始听课**：

- 顶部状态胶囊会变成"听课中"
- 左侧显示麦克风电平条与演示画面实时预览
- 中间实时滚动显示老师的原话（带时间码）
- 识别到任务后，「任务」页会自动出现条目并开始作答
- 下课后点 **停止**，软件自动收尾：补全课堂笔记 → 完成剩余任务 → 导出作业 → 打开输出目录

> 也可以在「设置 → 高级」里打开 **长时间静音自动下课**，软件会在连续 N 秒没人说话时自动收尾。

### 5. AI 是怎么"边听边做"的

整条链路是**流式**的：采集 → 语音识别 → 画面理解 → 汇总笔记 → 识别任务 → 作答 → 落盘，
每一步做完就立刻推进下一步，**不需要等下课**。

真机实测（20 秒切片 / 每 3 片汇总）：

    老师：同学们，今天这节课我们复习一元二次方程。        [+20.7s]
    老师：现在大家按照刚才讲的，完成这个任务：练习册第 32 页第 1 到第 5 题，下节课交。
                                                        [+40.7s]
    → 同一时刻：识别到任务 → 开始作答 → 作业已写入输出目录  [+40.7s]
    老师：（继续讲课，录音录像从未中断）                  [+60.7s] [+80.7s] …

也就是：**老师的话一落进识别结果，AI 立刻开始干活，同时继续听课**（录音、录像、
转写全程不受影响，作答题在后台线程池里跑）。

延迟由两段构成：

| 组成 | 说明 | 默认 | 调优建议 |
|------|------|------|----------|
| 语音切片 | 音频要攒够一个切片才送去识别，老师的话最多要等这么久才"被听到" | 20 秒 | 想边讲边跟做 → **5~10 秒** |
| 汇总节奏 | 每 N 个切片回头整理一次笔记并识别新任务 | 3 片 | 想更灵敏 → **1~2 片** |
| 模型耗时 | 整理笔记 + 识别任务 + 作答（取决于你的服务商与题目难度） | — | 无法通过配置消除 |

两个旋钮都在界面里：**设置 → 采集 → 切片长度**、**设置 → 高级 → 每 N 片汇总笔记**。
调快会更费 API 调用，按需权衡。

### 6. 老师分几次说完要求怎么办：主 Agent + 子 Agent

软件里其实有**两个 Agent**：

- **主 Agent（课堂督导）**：盯着老师新讲的内容，判断"这句话是不是在补充某个任务的要求"；
- **子 Agent（作业作答）**：只按主 Agent 维护的「任务简报」干活。

老师先说"完成这个任务"、过一会儿才补"必须用公式法、要写检验过程"时，主 Agent 会**自动调用工具**：

| 工具 | 作用 |
|------|------|
| `update_task_brief` | 把新要求 / 新截止时间 / 新细节**增补**进该任务的简报 |
| `redispatch_task` | 让子 Agent 用**更新后的简报**重新作答（原答案被覆盖） |
| `create_task` | 老师明确布置了此前没记录过的任务时新建 |
| `close_task` | 老师取消、或该任务已交代完毕 |
| `raise_question` | 听不清、拿不准时记录**存疑**交人工确认，不靠猜 |

真机实测（真实麦克风 + 屏幕采集，只把模型网络调用换成脚本）：

    [+18.7s] 老师：补充一下：解方程必须用公式法，而且要写出检验过程。
    [+18.7s] 主 Agent · update_task_brief：已更新「完成练习册第 32 页的题目」的简报：
                                        必须用公式法；写出检验过程
    [+18.7s] 主 Agent · redispatch_task：已让子 Agent 用最新简报重新作答
    [+18.7s] [产出] 01_P32第1-5题.md      ← 新版作业落盘，含公式法与检验过程

产物里的"要求"一栏和正文都变成了最新版本，不需要人工干预。

**降级保障**：如果所用的模型服务不支持 function calling（返回 400 等），
主 Agent 会自动切到本地启发式策略——仍然会把新内容补进简报并触发重做，
不会因为服务商不支持工具调用就彻底失效。

相关开关在 **设置 → 高级**：

| 选项 | 说明 |
|------|------|
| 启用主 Agent | 总开关，关掉就完全不督导 |
| 老师补充要求后自动让 AI 重做 | 关掉则只补简报、不自动重做 |
| 每任务最多自动重做 | 兜住 API 开销（默认 2 次，设 0 等于只补简报） |
| 单次督导最多工具轮数 | 防止模型反复调用工具（默认 3 轮） |

任务页的状态列会显示 `已完成 ↻（已自动重做 1 次）`，一眼能看出哪些作业被更新过。
存疑内容会写进课堂笔记的「存疑」一节，并在日志里给出醒目提示。

## 四、界面说明

左侧导航共六页：

- **听课**：状态、会话信息、开始/暂停/停止、电平、画面预览、实时转写、课堂笔记
- **任务**：任务表格。可 **立即完成 / 重做（可填修改要求）/ 打开产出文件 / 删除 / 手动添加任务**
  （老师口头布置、模型没听清时，手动补一条最省事）
- **作业产出**：本次会话产出的所有文件 + 一键「打开输出文件夹」+「导出本次会话」
- **历史**：所有听课记录；双击任意一条可以回看当时的转写、板书、任务与产出
- **日志**：运行日志，出问题时一键导出
- **设置**：模型 API / 个人信息 / 采集 / 作业输出 / 高级 五个页签

托盘图标常驻：可最小化到托盘，右键菜单可「开始听课 / 停止 / 显示主窗口 / 退出」。

### 模型 API

| 项 | 说明 |
|----|------|
| 服务商预设 | 通义千问 / OpenAI / 智谱 GLM / 硅基流动 / Kimi / Gemini / 本地 Ollama / 自定义 |

| 温度 / 超时 / 重试 | 默认 0.3 / 120s / 2 次 |

### 采集

| 项 | 说明 |
|----|------|
| 麦克风 / 系统回环 | 可独立开关；留空用系统默认设备 |
| 演示画面来源 | **窗口**（自动找极域）/ **区域**（自定义 x,y,w,h）/ **整屏** |
| 窗口标题关键字 | 默认 `极域, TopDomain, 电子教室, 教师演示, 学生演示, 屏幕广播` |
| 关键帧间隔 | 默认 8 秒抓一帧，画面变化超过阈值才留档 |
| 录制视频 | 默认开启，2 fps 存帧、H.264 合成，几分钟的课只占几十 MB |
| 单次时长上限 | 默认 240 分钟，防止忘了关 |

### 高级

| 项 | 说明 |
|----|------|
| 实时理解 | 边听边转写；关掉则只在停止时统一处理 |
| 自动完成作业 | 识别到任务立刻作答；也可以关掉改成手动点「立即完成」 |
| 最低任务置信度 | 低于该值只记录不自动作答（默认 0.35） |
| 启用主 Agent | 听到新信息后自动转给作业子 Agent（默认开） |
| 补充要求后自动重做 | 老师后补要求时让子 Agent 用最新简报重做（默认开） |
| 每任务最多自动重做 | 兜住 API 开销（默认 2 次，0 = 只补简报不重做） |
| 单次督导最多工具轮数 | 防止模型反复调用工具（默认 3 轮） |
| 下课静音判定 | 连续静音 N 秒视为下课（默认 300 秒） |
| 提示词覆盖 | 可逐条覆盖内置提示词，定制老师口吻/学科风格/输出格式 |

## 七、常见问题

**Q：抓不到极域电子教室的画面？**
设置 → 采集 → 点「刷新窗口列表」，从下拉里直接选中极域窗口；或者把「演示画面来源」改成"整屏"。
极域窗口最小化时软件会自动退回整屏抓取并记录一条警告。

**Q：听不到声音 / 转写全是空的？**
1. 检查「采集」里麦克风设备是否选对（点「刷新设备」）；
2. 如果老师的声音是从电脑音箱出来的，打开 **系统回环**；
3. 确认语音识别模型填了（`none` 类型表示不做识别）。

**Q：模型报 401 / 超时？**
到设置页点「测试连接」看具体错误。常见原因是 KEY 没开通对应模型、或 base_url 少了 `/v1`。
软件会自动对超时和 5xx 重试 2 次，失败的任务在「任务」页会显示为"失败"，点「重做」即可。

**Q：作业内容准确吗？**
AI 的作答基于课堂转写与板书，**可能有误**。软件会保留完整解题过程与自检结论，
请务必自己复核后再提交。任务页支持「重做」并填写你的修改要求，相当于给 AI 追加指令。

**Q：能不能只当录音录像工具用？**
可以。不填 API KEY 就无法开始听课（配置校验会拦截），但你可以只在设置里填假 KEY 并关掉
「实时理解」—— 采集与录像不依赖模型，停止后会留下音频、录像、时间轴。

**Q：数据会上传到哪？**
音频片段与画面关键帧会发送到**你自己配置的**模型服务商；其余全部留在本机。

### 开发中踩到并已修掉的坑（供维护参考）

1. **WASAPI 回环空闲时会卡死**：某些声卡（实测 Realtek）在"当前没有任何声音在播放"时，
   PortAudio 的阻塞式 read() 永远不返回，pa.open() 也可能永久阻塞。
   现在的做法：每个设备一个独立读取线程，打开带 4 秒超时，读取用 get_read_available()
   轮询后再读；卡住的句柄登记到"回收站"延后释放——绝不与 read() 并发调用
   stop_stream()/close()（那会直接触发 0xC0000005 把进程干掉）。
2. **画面采集 start() 曾空等 5 秒**：就绪事件只在采集线程退出时才 set，
   于是每次"开始听课"都白等 5 秒，而且采集线程早已在跑，会让录制时间轴与会话时间轴错位。
   已改为初始化完成立即放行。
3. **录像时间轴会"缩水"**：按"帧数 × 间隔"累计时间，抓帧/编码偶发超时会让 45 分钟的课
   只录出 35 分钟。现已改为以真实经过时间为准，并按"帧数 / 实际时长"计算编码帧率，
   保证录像时长 == 真实录制时长、与转写时间码对得上。
4. **采集启动不阻塞界面**：打开被占用/无响应的设备可能要几秒，引擎把采集启动放到
   后台线程，点"开始听课"立即返回（实测 0.01 秒）。

> QT_QPA_FONTDIR=C:\Windows\Fonts，否则中文会渲染成方块；正常桌面运行
> （windows 平台插件）没有这个问题。
